# Expense Tracker Pro — College Project

A free, responsive expense-tracking website made with **HTML, CSS, and vanilla JavaScript**.

## Features
- Add, edit and delete expenses
- Monthly budget, spending, remaining balance and progress bar
- Category-wise spending visualization
- Search expenses and filter by category or month
- Export filtered transactions as CSV
- Save expenses and budget in browser Local Storage
- Responsive design for desktop and mobile
- Optional sample data for project demonstrations

## Run locally
Open `index.html` in Chrome, Edge or Firefox. No installation, server or dependencies required.

## Publish for free with GitHub Pages
1. Create a free GitHub account at https://github.com if needed.
2. Click **New repository**. Name it `expense-tracker` and select **Public**.
3. Click **Create repository**.
4. Choose **Add file → Upload files**. Upload `index.html`, `style.css`, and `script.js` at the **repository root** (not inside another folder). You may also upload `README.md`.
5. Click **Commit changes**.
6. Open repository **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**. Choose **main** and **/(root)**, then **Save**.
8. Wait a few minutes. Your public site will normally be available at `https://YOUR-USERNAME.github.io/expense-tracker/`.

If the page is not live immediately, check the repository's **Actions** tab for deployment status, then refresh Pages settings.

## Important
Local Storage is specific to each browser/device. Expenses do not sync across devices, and clearing browser storage removes saved data. GitHub Pages hosts static files; it does not provide an online database or login system.
